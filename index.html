Decryptor API

Unified REST API for decrypting VPN and proxy config files. Supports HTTP Custom, EHI, NPVT, SSC, and Dark Tunnel formats — upload a file, send base64, paste a string, or fetch from a cloud URL.

5 supported formats
File upload, base64 & string input
Cloud link fetch (EHI)
Max 10 MB per file

Supported Formats

The API auto-detects the format from the file extension, or falls back to magic-byte inspection.

.hc
HTTP Custom
.ehi
EHI Config
.npvt
NPVT Config
.ssc
SSC Config
.dark
Dark Tunnel
.darktunnel
Dark Tunnel (alt)
.darkcloud
Dark Cloud
ℹ️
When a filename has no recognised extension, the API checks the first bytes of the file (magic bytes) to detect .npvt and .ssc automatically.
Response envelope
{
  "status":    "success",
  "extension": ".hc",
  "filename":  "config.hc",
  "decrypted": "...decrypted content..."
}

        POST
        /decrypt
      

      
Upload a config file using multipart/form-data. The field name must be file. The API infers the decryptor from the filename extension. Maximum file size: 10 MB.


      

        
Parameters · multipart/form-data

        

          
NameTypeRequiredDescription

          

            file
            binary
            required
            The encrypted config file. The filename extension determines which decryptor is used.

        POST
        /decrypt/base64
      

      
Send an encrypted file as a base64-encoded string inside a JSON body. Useful when you cannot send multipart form data (e.g. from mobile apps or scripted environments). Data-URIs are accepted — the data:…;base64, prefix is stripped automatically.


      

        
Body · application/json

        

          
FieldTypeRequiredDescription

          

            file
            string
            required
            Base64-encoded content of the encrypted config file.
          

          

            filename
            string
            optional
            Original filename including extension (e.g. config.ehi). Used to pick the correct decryptor. Defaults to unknown.bin.

Python

          
import base64, requests
with open("config.hc","rb") as f:
    b64 = base64.b64encode(f.read()).decode()
r = requests.post("/decrypt/base64",
    json={"file": b64, "filename": "config.hc"})
print(r.json())

        

      

    


    
    

      

        POST
        /decrypt/darktunnel
      

      
Decrypt a Dark Tunnel configuration string. The string can include the darktunnel:// prefix — it is stripped automatically. Whitespace is also cleaned before decryption.


      

        
Body · application/json

        

          
FieldTypeRequiredDescription

          

            string
            string
            required
            The Dark Tunnel config string. May include the darktunnel:// scheme prefix.
          

        

      


      

        ⚠️
        
The string is decoded with the Dark Cloud decryptor. Make sure the string is a valid Dark Tunnel / Dark Cloud encoded payload — raw JSON or plain text will fail.

        POST
        /decrypt/ehi-cloud
      

      
Fetch an EHI config file from a https://ehi.link/… cloud URL and decrypt it on the fly. You can supply the full URL or just the key (the short code at the end of the URL).


      

        
Body · application/json

        

          
FieldTypeRequiredDescription

          

            url
            string
            optional*
            Full EHI cloud URL, e.g. https://ehi.link/WPKKACR9
          

          

            key
            string
            optional*
            Short key from the URL, e.g. WPKKACR9. Used to build the URL automatically.
          

        

        
* Either url or key must be provided.
